# Lake Canoe

A small 2D browser game: paddle a wooden canoe with a fisherman aboard
around a lake, bounded by a land border on the screen edges.

## Running it
Just open `index.html` in a browser — no build step, no install.
Phaser is loaded from a CDN.

(If you want to run it from a local server instead of opening the file
directly, any static server works, e.g. `npx serve .` or Python's
`python3 -m http.server`.)

## Controls
- **W** — up
- **A** — left
- **S** — down
- **D** — right
